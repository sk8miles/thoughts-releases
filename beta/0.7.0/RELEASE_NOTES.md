# THOUGHTS Beta 0.7.0 (build 27.9)

Apple Silicon beta for macOS 14 or later.

## Changes

- Makes selection and waveform dragging reliable in transparent Catch mode.
- Gives Catch keyboard focus when opened or clicked so Command-C is received consistently.
- Keeps ordinary transparent mode click-through and reserves Command-drag for moving the window.
- Keeps the pin, jellyfish and Catch controls available in transparent mode.
- Includes the brighter Autumn waveform gradient introduced in build 27.8.

## Installation

Unzip the download and open `THOUGHTS Beta.app`. This beta is ad-hoc signed and not notarized, so macOS may require Control-click → Open on first launch. Grant Screen & System Audio Recording access when requested.

After copying a Catch selection, wait for `Audio file copied`, switch to the destination application, and paste there.
